# 拾数 · 彩票选号实验室

双色球与大乐透参考选号、复式计算、号码保存和开奖核对网站。

**在线使用：[shishu-lottery-lab.xiaoccchuan.workers.dev](https://shishu-lottery-lab.xiaoccchuan.workers.dev)**

## 功能

- 单式 1–50 注、复式“几加几”、1–99 倍与大乐透追加，实时计算组合数、金额及一等奖覆盖概率。
- 随机、热号、冷号和遗漏加权选号，蓝球或后区组合可分散覆盖。历史加权没有已验证的预测优势。
- 浏览器本地保存、号码文本导出、JSON 备份导入导出。
- 私人同步码：号码在浏览器中加密后存入 Cloudflare，手机与电脑输入同一码即可恢复、合并和同步。
- 按官方期号或手动奖号核对，精确统计复式、倍投与追加权益；不计福运奖和派奖。
- 中奖规则对照表与命中个数速查，展示固定奖金、大乐透两档奖池金额、追加说明及历史九奖级规则；核奖页可跳转到所选期号适用的规则。
- 五年公开开奖数据、号码频次和回测结果；在线刷新最近100期，数据源异常时保留快照并明确提示。

## 云端保存

1. 在“我的号码”中点击“启用云端同步”，创建私人同步码。
2. 复制并妥善保管同步码。其他设备打开同一网站，输入此码连接。
3. 本机已有号码会与云端合并。保存、删除、核奖后自动同步；离线保存后在联网或再次打开页面时重试。
4. “立即同步”可主动获取另一台设备的更新。“断开”只移除本机连接，保留本机与云端号码。

同步码相当于号码库的钥匙，持有人可以读取和修改记录。没有账号、邮箱或密码找回功能。JSON 号码备份不包含同步码。本地缓存为明文，共享设备使用完请清理浏览器数据。

```sh
npm ci
npm run build
npm test
npm run dev
```

本地地址为 `http://localhost:8787`。保持开发服务器运行，在另一终端执行真实 Worker / SQLite 接口测试：

```sh

```

测试覆盖核奖规则、复式计数、加密与篡改校验、并发保存合并、删除不复活、离线恢复、同浏览器多标签页竞争、访问隔离和旧版本写入冲突。

## Cloudflare 部署

```sh
npx wrangler login
npm run deploy
```

`wrangler.jsonc` 配置静态资源、Worker 和 SQLite Durable Object。首次发布同步功能时，`v1` migration 会创建 `LotteryVault`。不要删除已发布的迁移记录。部署前确认目标账号、Worker 名称和现有资源。

- `GET /api/draws?game=ssq|dlt`：固定官方数据源代理，缓存15分钟。
- `GET /api/health`：应用版本。
- `POST /api/vault`：新建私人同步空间；`GET` 读取；`PUT` 按版本写入。

同步码使用256位随机数。浏览器通过 HKDF 派生独立的访问令牌和 AES-256-GCM 密钥；原始同步码与加密密钥不会发送至服务器。访问令牌通过 HTTPS Authorization 头发送，服务端将其 SHA-256 摘要用于隔离空间，只存储密文。接口校验来源、数据大小和版本号，不提供号码库列表。

同步使用每条记录的逻辑时钟、删除标记和整份密文的版本比较。并发写入冲突后重新读取并合并；不会用本机旧列表直接覆盖云端。每个空间最多200组有效方案，保留最多5000条含删除标记的记录。超限时保留现有记录并提示整理，不会静默裁剪。

## 文件与数据

- `public/`：前端及公开历史快照；`server/vault.js`：持久化同步接口；`worker.js`：入口。
- `scripts/build-data.mjs`：从研究快照构建 `public/history.json`。
- `research.py`、`five_year_research.py`、`data/`：公开开奖数据与可复现研究材料。
- [五年研究](FIVE_YEAR_RESEARCH.md) · [研究方法](FIVE_YEAR_METHOD.md) · [网站说明](WEBSITE.md)。

仅 `public/` 及 Worker 代码会部署。个人选号文件 `number.txt`、本地数据库、环境变量、凭证和依赖目录均不纳入版本控制。
